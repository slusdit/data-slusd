TPO - Stores Third Party Options for use with Aeries APIs
TPP - Stores Third Party Permissions.
TPS - Stores calculated status for Algebra I, CAHSEE, and Physical Fitness
TRM - Define school terms
TSA - Aeries Web Only. Used by the Teacher Portal to store which students are linked to a teacher and how. Associated with the TAA table and populated dynamically when a teacher logs in to Aeries Web.
TSD - Stores teacher defined standards by class.
TSI - Temporary Student Information
TSO - Stores standard grading options by teacher and class.
TST - Contains a history of State and Local standardized test scores
TTC - Contains a list of tables to copy when transferring a student between schools
TTM - Stores starting and ending dates for terms defined in HIS for all previous years. CSIS use ONLY.
TTP - Defines which Test Scores, Activities, Immunizations, Student fields etc. are to print on Transcripts
TXT - Stores letters developed in the QUERY Letter Text Editor, some of which can be District Standard
UAO - Contains User Account Options for use with Google Classrooms.
UCE - UC ELC Extract
UGA - Aeries Web security table to store User and Group Memberships.
UGC - Aeries Web security table for code-based security. Currently used only in specific areas of the system such as Financials.
UGN - Aeries Web security table to store information about Users and Groups.
UGP - Aeries Web security table to store permissions granted to Users and Groups.
USO - Stores various options for individual users that need to be associated with an individual database
USR - Aeries Client Only. Stores permissions for the different users to access various schools.
UTZ - System Check
VAC - Utilized to update required immunizations for the current state requirements.
VER - Contains the sheet numbers of absence verification sheets printed
VIC - Store information for Victims of harassment or any other offenses
VIS - Contains detail for one of the two Counselor Tables - Less detail than CNF (both can be used)
VND - Vendors for the Textbooks
VSN - Contains history of details of Vision Tests
WEB - Contains information about the valid users of ABI - Not used for Aeries Web
WGM - Contains global messages displayed to users
WIA - Contains the assignment scores for the What If feature available in the Aeries Student app
WIG - Contains the student ID, gradebook number, gradebook term and other settings for the What If feature available in the Aeries Student app
WIH - Contains score goals and other settings for the What If feature available in the Aeries Student app
WIT - Store information for Witnesses of harassment or any other offenses
WPT - Record of Work Permits issued to Students
WPV - Aeries Web Only. Contains information about visits to work places by CTE/ROP teachers when students are interning at places of employment.
WRL - WRL Log
XRF - Tool for District to match criteria required by Testing Pre-IDs and location of data in AERIES
YTD - Contains Student Attendance data from the beginning of school to the current date
